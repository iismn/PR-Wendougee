# Wendougee branding

The circular symbol replaces the former GeeFlow drop throughout the UI and launcher assets. The start screen uses the symbol above the requested display word “Wendougee”. The app display name remains Wendougee LITA.

Source: [Wendougee official website](https://en.wendougee.com/?lang=en), [original white wordmark PNG](https://en.wendougee.com/en_uploads/allimg/20260516/1-2605161F451L4.png), retrieved 2026-11-16. The original is retained here as wendougee-official-wordmark.png. The symbol's three circles are represented as a scalable even-odd path with normalized proportions measured from that original. It can be tinted for day and night without a bitmap background.

The mark is Wendougee's branding. Upstream GeeFlow copyright and GPL notices remain in place. Launcher assets use the same circular geometry on a dark navy base; regenerate them on Windows with scripts/generate-brand-assets.ps1.
